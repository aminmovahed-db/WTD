# E2E scenarios (manual for v1)

The following smoke checks should be run against the packaged macOS app:

1. Create tasks in each column and restart app; verify persistence.
2. Drag task from Backlog to Today and then Done; verify order and completion behavior.
3. Archive task from Done and restore from Archive view to either Backlog or Done.
4. Export JSON, then import with replace mode; verify board state is restored.
5. Add long notes and large number of cards; verify layout remains usable.
